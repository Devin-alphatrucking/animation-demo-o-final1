## Usage status — read this first

| Status | Meaning |
| --- | --- |
| **Supplied by owner** | Provided directly by the business owner. |
| **Manufacturer — permission not verified** | Official photography downloaded from the manufacturer's own India website. Retailers commonly use this under authorised-reseller / channel-partner marketing terms, **but OM Telecom's rights to use these images have not been verified**. Confirm with each brand (or your distributor) before going live, or replace with images from your partner asset portal. |

No AI-generated images, synthetic renders, CSS phone mockups or competitor photographs are used anywhere. Where OM Telecom's own photography is needed (stores, staff, founders) the site shows a clearly labelled **Photo placeholder** instead.

## Considered and rejected

- **Wikimedia Commons / Openverse store photos** (CC BY / CC BY-SA, licences verifiable): every usable result showed another business's signage (e.g. Singapore, Malang, Shenzhen, Hong Kong shops) or was too low-quality for a premium site. Using them would imply those stores belong to OM Telecom, so none were used.
- **Unsplash**: the API requires an access key; nothing was downloaded.
- **Competitor photography** (Mehul Telecom, KORE, PhoneWale, etc.): never used.

## Prices

The `price` field in `src/data/products.ts` holds the **starting price for the base variant, as rendered on the manufacturer's own India website or online store on 6 Nov 2026**, before bank or exchange offers. Each product's `priceSource` records where it came from:

- Apple: apple.com/in/shop/buy-iphone/… ("or ₹…" full price)
- Samsung: samsung.com/in/smartphones/…/buy/ (selling price, not MRP)
- OnePlus: oneplus.in/store/phone ("From ₹…")
- vivo: shop.vivo.com/in (listed price). **vivo X300 Pro is not listed in the store, so its price is `null`.**
- OPPO: oppo.com/in/smartphones ("From ₹…")
- Xiaomi/Redmi: mi.com/in store listings and the Xiaomi 17 Ultra buy page

These are reference prices, **not OM Telecom store prices**, and brands change them often. Re-check them before launch, or replace them with your own store pricing.
